    Som do jogo sem a voz do Discord

    O navegador manda o som do dispositivo de saída padrão do Windows. O truque é deixar o Discord tocar direto no fone, fora desse padrão. Faça uma vez e fica salvo:

    1. Instale o VB-Audio Virtual Cable (grátis, em vb-audio.com/Cable) e reinicie o PC.
    2. Configurações do Windows › Sistema › Som › Saída: escolha CABLE Input. O jogo passa a tocar no cabo.
    3. Para continuar ouvindo o jogo: aperte Win+R, digite mmsys.cpl, aba Gravação › CABLE Output › Propriedades › Escutar. Marque “Escutar este dispositivo” e escolha seu fone.
    4. No Discord: Configurações › Voz e vídeo › Dispositivo de saída: escolha o seu fone, não “Padrão”.

    Pronto: o Telão manda só o que passa pelo cabo (jogo, música) e a call vai direto para o seu fone. Para desfazer, volte a saída do Windows para o fone.
